# Rômulo Gonzaga

**Educação tecnológica · Ferramentas web · Inovação aplicada**

Atuo na educação tecnológica e desenvolvo ferramentas web para apoiar o ensino, o planejamento de projetos e a gestão de informações. Aqui reúno aplicações em HTML, CSS e JavaScript e iniciativas educacionais com orientação de projetos de alunos.
